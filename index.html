Healthcare & Insurance Analytics

About this analysis

The notebook covers data quality, exploratory analysis, feature engineering, and a leakage-aware Paid/Denied classification example. Open the notebook on GitHub or download it to run the analysis locally.

Educational use only

The dataset is synthetic and does not describe real patients, hospitals, or insurers. This project is not medical advice and must not be used to make insurance decisions.
